## Local development

```bash
npm ci
npm test
npm run build
npm run verify
npx pagefind --site _site --serve
```

`npm run build` generates the static site and a fully client-side Pagefind index in `_site/`. Search requires serving `_site/` over HTTP rather than opening `index.html` directly.
